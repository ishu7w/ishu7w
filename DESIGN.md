# Deep green × antique gold × temporal filaments

The profile pairs the supplied gold Loki helmet with a dark emerald field and TVA-inspired temporal strands. The helmet banner stays crisp and unobstructed; repeated section ribbons carry the motion through the page.

`assets/tva/divider.gif` is generated by `scripts/animate_loki.py`. Its loop layers softly undulating green filaments, gliding specular light, and restrained depth-of-field glow over a dark emerald atmosphere. GIF is used because GitHub profile READMEs support animated GIF images; the key information and project links remain native Markdown.

Project panels use the same emerald palette and strand motif in `assets/tva/projects.svg`. GitHub controls the surrounding profile page background, so the theme lives in the banner, animated section ribbons, and project art.
