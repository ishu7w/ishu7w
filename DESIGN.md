# Deep green × antique gold

The profile now takes its main visual direction from the user-provided Loki horned-helmet artwork: a flat, deep-green field and a bold gold helmet. The supplied artwork replaces the previous drawn person and chronal restraints in the hero. The matching banner pairs that exact cropped helmet artwork with Ishu’s profile title and technical focus.

Project panels use the same green-and-gold palette with subdued gold borders and linework. Section separators use a fine antique-gold trace. The page keeps key details in native Markdown for readability and link access. GitHub does not allow a profile README to set the whole page background, so this palette is carried by the hero and local graphic panels.

Assets: `assets/tva/helmet-profile.png` is composed from the provided helmet image; `assets/tva/projects.svg` contains the four project panels; `assets/tva/divider.svg` is the section separator.
